特寫：神龍太空飛機（第 4 次任務）× Object H — 部署、訪問與回收全程回放

primary 69673（OBJECT H，2026-024H）× secondary 67689（PRC TEST SPACECRAFT 4，2026-024A）

背景 — 中國第 4 架可重複使用試驗太空飛機（NORAD 67689，2026-024A，2026-02-07 酒泉發射，西方稱 Shenlong「神龍」）於 605 km / 49.99° 軌道運作。2026-06-22 釋放一顆 小型衛星 Object H（NORAD 69673，2026-024H）。H 隨後機動離開、前往「上一次任務（2023-195） 釋放的 Object G（59884）」繞行偵察，再折返太空飛機並於 7 月中旬被回收—— 美國第 18 太空防禦中隊（18 SDS）與 LeoLabs 均作此評估，路透社 2026-08 報導即此事件。 本案例以 Space-Track 公開 TLE 逐日 SGP4 重建，時序與 LeoLabs 完全一致。

逐段時序（回放時對照畫面右側時間軸）

2026-06-22
部署：H 自太空飛機釋放，兩者相距僅 ≈0.2 km、近乎共位。
06-24 ~ 07-06
離開：H 沿軌道漸行漸遠，前往訪問 Object G（H–太空梭距離升至約 1,000 km）。
07-08 ~ 07-11
返回：訪 G 結束後折返，H–太空梭 722 → 5 km——逆轉自然漂移需要推力，是「受控接近」的直接證據。
07-12 ~ 07-14
回收：兩者距離 ≈0 km，地面感測器已無法分辨；18 SDS 評估 H 已被太空飛機收回。
07-14 之後
共位：編目上 H 與太空飛機維持近乎相同軌道（≈0 km）。
怎麼看回放： ① 左側「距離–時間」曲線是主線索：V 字谷 = 接近事件，貼地 0 = 回收； ② 3D 視角預設「第三方遠景」綜觀整個事件（時間軸下方色帶＝部署/訪 G/返回/回收四階段），按「切換視角」可循 遠景 → H → 太空飛機 輪替； ③ 紅線是兩者連線（越紅越近），紅點標最接近時刻； ④ 播放速度已調為全程約 3 分鐘，時間軸可拖曳到 07-12 直接看回收段； ⑤ 3σ 橢球代表 TLE 級不確定度——次公里距離落在雜訊底，回收段請看趨勢而非單點數值； ⑥ 右側浮動「相對軌跡投影」視窗與時鐘同步：以太空飛機為原點的 沿軌T–Δ高度 平面， 粗線＝單圈平均趨勢——衛星繞圈看不出的軌道升降，在這裡一眼可見（可拖曳、⇄ 換中心）。
