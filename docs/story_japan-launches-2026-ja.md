# 2026年6月〜8月 日本の衛星打ち上げ観測誌

**全地球の衛星分布から単一衛星、そして2衛星の相対運動へ — 5つの観測レベルと1つの打ち上げイベント索引**

全地球の衛星分布から段階的にズームイン：日本の衛星 → QZSS（みちびき）星座 → 今季の新規打ち上げ衛星 → 単一衛星の軌道パラメータ → 2衛星の幾何学的接近。本ストーリーの位置・軌道表示は、取得可能な最新の公開 TLE を用いた準リアルタイム SGP4/SDP4 伝播結果であり、リアルタイムのセンサー追跡値、精密暦、確認済みの近接運用ミッションを示すものではありません。

### 利用上の制限

本展示は取得可能な最新の公開 TLE を基礎とし、SGP4/SDP4 による準リアルタイム軌道伝播で、星座の状況、軌道異常候補、地上局可視性、近距離の幾何学的イベントを統合したものです。結果は公開データと簡略モデルによる技術デモであり、精密暦、実際のレーダー探知能力、確認済みマヌーバ、運用レベルの衝突確率を示すものではありません。

| 制限 | 影響 |
|---|---|
| 公開 TLE + SGP4 | 位置は準リアルタイム伝播の推定値であり精密暦ではない；精密編隊や運用レベルの判断には不適 |
| 固定共分散 σ_R/T/N | Pc は proxy／順位付け値であり CDM 衝突リスクではない；3σ 楕円体は概念図 |
| 軌道長半径ジャンプ閾値 | マヌーバ結果は「候補イベント」であり確認済みマヌーバではない；Δv は近円・接線インパルスの等価推定 |
| 幾何学的可視性モデル | 地上局評価は可視性／観測カバレッジであり、レーダー方程式を含まず探知能力を意味しない |
| 公開分解能の推定 | センサー／分解能分類は公開情報に基づく分類であり、実際のミッション性能ではない |
| 名称ルール分類 | 星座／国／用途はカタログ名称と metadata ルールで判定し、データの完全性に影響される |

## はじめに

2026年6月12日、H3-30S（F6）が種子島宇宙センターから6機の衛星を軌道に投入。8月10日には H3-22S（F9）が準天頂衛星 QZS-7 を打ち上げた。本ストーリーは全地球の視点から始まり、一機の衛星の日次軌道パラメータの推移まで段階的にズームインする。

## ⑦ 2衛星の幾何学的接近デモ（/rpo）

本システムの2衛星相対接近シーン：公開カタログ事例から2物体の相対幾何 3D ビュー、最接近距離、R/T/N 相対成分、Pc proxy（衝突リスク順位付けの代理値：Chan 2-D 簡略式・相対 RTN 座標系での固定的な概念的 σ・等価衝突半径 5 m、運用レベルの衝突確率ではない）を再構成。手順：2衛星の TLE 重複期間を 30 分のサンプリング間隔で粗走査して全体の最小距離を求め、最接近時刻 ±12 h を 60 秒間隔で精走査する。事例タイムラインに公開されたミッション背景情報が付されている場合（各事例の出典と信頼度は各ページの説明を参照）を除き、本シーンは公開 TLE から導出した幾何学的な接近表示であり、確認済みの近接運用（RPO）行動を意味しない。

## まとめ

3万物体の全地球分布から、1機の衛星の日次軌道パラメータ、そして2機の相対運動まで——同じ公開 TLE データが5つの観測レベルの宇宙状況把握を支えている。準リアルタイムであってリアルタイムではない。幾何学的な接近であって衝突リスク判定ではない。TLE 平均軌道要素の傾向であって精密暦ではない。
